# Someone's Demo Manager
LAN Music Demo Manager

"Someone's Demo Manager" (SDM) is someone's self-hosted 
web application used for someone's Demo Managing,
It runs on Someone's LAN. Working as a someone's LAN 
File manager for someone's music demos.

Currently someone's developing it and neither the someone
nor the application is stable

Written in P*thon

---

## Installation
The only library that needs an installation is NiceGUI

```
pip install nicegui
```

Im actively avoiding external libraries for this specific project
---

## Usage
Run the server
```
python main.py
```

The application will start running on your default browser, you will intuitively know  the usage of the program since it's very 
simple and intuitive.

## Accesing the files
All demo files generated with SDM can be found in the directory `.demosfiles`, placed along with the `main.py` file. `.demosfiles` and SDM are independent, you can backup the directory, move it or delete it,
SDM will simply create a new one if it doesn't exist.
